# Sistema de Gerenciamento de Barbearia

## Trabalho Final – Algoritmos e Programação (A3)

Projeto desenvolvido como trabalho final da disciplina de Algoritmos e Programação, com o objetivo de aplicar os conceitos de Programação Orientada a Objetos (POO) por meio da criação de um sistema de gerenciamento de uma barbearia.

A aplicação permite organizar clientes, funcionários, serviços e atendimentos, além de registrar pagamentos e consultar faturas.

## Funcionalidades

- Cadastro e consulta de clientes.
- Cadastro, consulta e atualização de serviços.
- Registro e gerenciamento de atendimentos.
- Controle de pagamentos.
- Consulta de faturas e total recebido.
- Cadastro e gerenciamento de funcionários.

## Tecnologias utilizadas

- Java

## Conceitos aplicados

- Classes e objetos.
- Encapsulamento.
- Herança.
- Polimorfismo.
- Abstração.
- Construtores.
- Getters e Setters.

## Como executar

1. Clone ou baixe este repositório.
2. Abra o projeto em uma IDE compatível com Java.
3. Execute o arquivo `Programa.java`.
4. Utilize o menu apresentado no console para interagir com o sistema.
